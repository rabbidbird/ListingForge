# Platform checklist sources

Reviewed August 23, 2026. These constraints are a small, conservative drafting
checklist—not a compliance service, ranking model, or substitute for the current
marketplace rules for a seller's category and country.

| Surface | SellerDrafts check | Qualification | First-party source |
|---|---:|---|---|
| Etsy title | 140 characters | Etsy permits up to 140 and suggests considering fewer than 15 words. | [Etsy Help: Create a listing](https://help.etsy.com/hc/en-us/articles/115015628707-How-to-Create-a-Listing) |
| Etsy tags | Up to 13; 20 characters each | SellerDrafts does not manufacture filler tags merely to reach 13. | [Etsy Help: Tags](https://help.etsy.com/hc/en-gb/articles/360000336307-How-to-Use-Tags-to-Get-Found-in-Search) |
| Amazon item name | 75 characters | Effective July 27, 2026 for non-media categories. Media/category exceptions must be checked in Seller Central. | [Amazon announcement](https://sellercentral.amazon.com/seller-forums/discussions/t/145b6d0f-999c-4555-896c-c694bda2e470) |
| Amazon title characters | Warn on `! $ ? _ { } ^ ¬ ¦` | Brand/category exceptions can apply; SellerDrafts warns rather than claiming universal rejection. | [Amazon title-policy announcement](https://sellercentral.amazon.com/seller-forums/discussions/t/c9d67ab5-b7ef-4d79-a371-bcf70dd08ddf) |
| Shopify SEO page title | 70-character drafting target | This is Shopify's search-engine page-title field guidance, not a claim that every product H1 has a 70-character hard limit. | [Shopify Help: SEO keywords](https://help.shopify.com/en/manual/promoting-marketing/seo/adding-keywords) |

Marketplace guidance changes. The UI therefore labels every score as a heuristic,
shows category/media caveats, and requires users to confirm current rules before
export.
